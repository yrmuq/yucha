What this image contains:

  yucha
    Source: https://github.com/yrmuq/yucha
    License: GPL-3.0-or-later

  Syncplay 1.7.7 client, unmodified
    Source: https://github.com/Syncplay/syncplay
            and third_party/syncplay in the yucha repository
    License: Apache-2.0, plus the per-file ISC, BSD, and MIT notices
            that stay on those files. Syncplay's license is
            third_party/syncplay/LICENSE. Its third-party notices are
            third_party/syncplay/syncplay/resources/third-party-notices.txt.
    yucha does not patch these files and does not open Syncplay's window.

  CPython 3.12.15
    Build: https://github.com/astral-sh/python-build-standalone/releases/tag/20261013
    License: Python Software Foundation License
    File: cpython-3.12.15+20261013-x86_64-unknown-linux-gnu-install_only_stripped.tar.gz

  libmpv
    Copied from the build machine's libmpv package, with the libraries
    it needs. This is the engine that draws the picture. It does not
    open a window. Upstream is the same mpv project.
    License: GPL-2.0-or-later
    Syncplay asks a program named mpv for its version. The image
    answers with a stub that prints this package's version. No second
    mpv program is bundled.

Python dependencies (Twisted, its TLS stack, PySide6 Essentials, and
python-mpv) are installed from PyPI into the bundled interpreter. Their
licenses stay with those packages. PySide6 Essentials is the Qt for
Python bindings that the window uses, LGPL. The WebEngine, add-on, and
PDF modules are not installed. python-mpv is GPL-2.0-or-later or
LGPL-2.1-or-later, same terms as libmpv.
